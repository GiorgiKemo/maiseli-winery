# Maiseli Winery

A responsive Maiseli Winery website built with Next.js and Tailwind CSS, with original winery content and supplied photography.

Install dependencies with `npm install`, then run `npm run dev` and open http://localhost:3000. Use `npm run build` to create a production build, `npm start` to serve it, and `npm run check` to type-check the app. The original page copy, styling, and interaction script are retained in `dist` as the source of truth; files served by Next.js are in `public`.

## Content and assets

Copy is based on the supplied Maiseli Winery document. Photographs are optimized WebP versions of the two supplied photo archives. The original source materials are preserved in the parent workspace. No reference-site images or copy are reused.

The site includes all eight wines in three collections, wine detail dialogs, the family story, vineyard, winemaking accordions, and a cellar photo gallery. Cormorant Garamond and DM Sans are loaded through Google Fonts, with local system fallbacks.

## Before publication

- Confirm final copy and bottle photography with the winery. No product prices, availability, vintages, tasting notes, or certifications have been invented.
- Supply the winery’s public contact details and exact location if a contact or visit section is wanted. No booking or contact form is connected.
- Rkatsiteli in the Heritage collection uses a clearly labelled cellar photo because a corresponding bottle photo was not supplied.
- Review any market-specific publication requirements. There is no store, payment processing, or direct alcohol ordering.
- Choose a production domain before public launch. Sites is configured for an owner-only design preview.

The wordmark is a typographic treatment; no standalone official logo was supplied.
